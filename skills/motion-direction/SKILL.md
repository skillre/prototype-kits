# SKILL · Motion Direction

> **禁止 animation everywhere。**
> 任何动效必须能归入四类角色之一。归不进去 → 删掉它。

动效不是"让页面活起来"的装饰。它只有四个合法用途：

| 角色 | 用途 | 例子 |
|---|---|---|
| `enter` | **层级**：告诉用户先看什么 | 内容进入视口逐段揭示 |
| `interact` | **反馈**：确认输入已被接收 | 按钮 hover/active、光标形态变化 |
| `ambient` | **空间**：营造纵深与氛围（**不携带信息**） | 环境光呼吸、网格漂移 |
| `data` | **数据交互**：图形与读数的响应 | 数值刷新、曲线重绘 |

---

## 1. Motion Hierarchy（动效层级）

动效的"重要程度"必须与它在页面里的层级一致。层级越高 → 越慢、越大、越完整；
层级越低 → 越快、越小、越克制。

```
L1  页面级     进入动效（reveal / stagger）      最长，最完整
L2  区块级     卡片/面板进入                     中等
L3  元素级     按钮、标签、光标的交互反馈          最短，只求"被感知"
L4  环境级     背景光、网格（无信息）             极慢且必须可关闭
```

**铁律**：L3 的时长必须短于 L2，L2 必须短于 L1。
如果按钮反馈比页面入场还慢，用户会觉得界面卡。

---

## 2. Duration Ranges（时长区间）

| 层级 | 角色 | 区间 | 说明 |
|---|---|---|---|
| L3 | interact | **50–250ms** | 超过 250ms 的按压反馈 = 感觉卡顿 |
| L1/L2 | enter | **200–700ms** | 低于 200ms 看不出层次；高于 700ms 用户开始等 |
| L4 | ambient | **4000–12000ms** | 必须是"察觉不到循环"的量级 |
| — | **绝对上限** | **1000ms** | 交互动效绝不允许超过 1 秒（由 `assertStylePackMotion` 强制） |

### 各 pack 的实际刻度

| pack | instant | quick | base | slow | ambient | 性格 |
|---|---|---|---|---|---|---|
| editorial | 80ms | 140ms | 220ms | 480ms | 12000ms | 克制：纸不会自己动 |
| cinematic | 120ms | 220ms | 360ms | 720ms | 9000ms | 氛围：空间需要时间被感知 |
| instrument | 50ms | 100ms | 160ms | 220ms | — | 精确：仪表不做慢动作 |

### 缓动

| 用途 | 曲线 | 为什么 |
|---|---|---|
| 出场/进入 | `ease-out`（陡起缓收） | 重物落定感；先快后慢符合"到达"的物理直觉 |
| 双向过渡 | `ease-in-out` | 起止对称，适合循环 |
| 持续/仪表 | `linear` | 仪器是恒速的，曲线会引入不存在的"情绪" |
| 微交互 | 轻微 `spring` | 只给 ≤ 8px 位移的元素；大元素回弹会晕 |

**禁止**：`ease-in` 用于进入动画（慢启动 = 感觉迟钝）；
对所有元素使用同一条曲线（层级就消失了）。

## 3. Interaction-triggered Motion（交互触发的动效）

只有三类交互可以触发动效，且每一类都有明确的作用范围：

| 触发 | 允许动什么 | 禁止动什么 |
|---|---|---|
| **hover** | ≤ 2px 位移、颜色、边框、光斑 | 尺寸变化（会推挤布局） |
| **active/press** | 颜色反色、≤ 1px 下沉 | 弹性缩放（会让"按下"感觉不可信） |
| **pointer move** | 视差、光斑跟随、光标（**必须 rAF 合并**） | 每帧写 DOM 尺寸；直接改 `top/left` |

### 指针动效的三条硬约束

1. **必须 rAF 合并**：`pointermove` 只记录坐标，写入发生在下一帧。
2. **只写 CSS 变量或 `transform`**：绝不改 `top/left/width/height`。
3. **必须有能力探测**：粗指针（触屏）下不注册监听。

---

## 4. Reduced Motion

`prefers-reduced-motion: reduce` 不是"关掉所有设计"，而是"**去掉运动，保留信息**"。

| 动效类型 | reduced-motion 下的处理 |
|---|---|
| 位移动画（translate/scale） | **必须移除**（这是前庭反应的主要来源） |
| 透明度淡入 | **保留**（不引发前庭反应；且避免"突兀出现"像加载失败） |
| 颜色/边框变化 | **保留**（它是状态信号，不是装饰） |
| 持续环境动画 | **移除**（无法被用户暂停的持续运动是明确的有害项） |
| 滚动驱动动画 | **移除**（用户无法控制触发时机） |

### 例外：instrument 不保留淡入

`instrument` 的 `reducedMotion.keepOpacity` 是 `false`。
理由：监控面板上的状态切换**必须瞬时可见** —— 加淡入会延迟告警的感知，
这在仪表的语义下是错误而不是关怀。

> 这条差异是刻意记录的：降级策略不是全局统一值，而是**由 pack 的语义决定**。

### 实现要求（双保险）

```css
/* CSS 层兜底 */
@media (prefers-reduced-motion: reduce) {
  :root { --kits-pointer-factor: 0 !important; --kits-enter-distance: 0px !important; }
}
```

```ts
// JS 层：不仅降级，还要真的不注册监听
const allowed = useMotionAllowed(disableMotion);
if (!allowed) return; // 不注册 pointermove / 不创建 observer
```

两条都要有：CSS 兜底应对"JS 未执行"，JS 探测应对"运行中改变偏好"
与"省掉事件处理成本"。

## 5. Mobile Constraints（移动端约束）

| 约束 | 原因 |
|---|---|
| 指针视差一律关闭 | 触屏没有 hover；手指拖动 = 滚动，跟随会造成误触发与掉帧 |
| 环境动效默认关闭 | 省电；移动 GPU 预算更紧 |
| 位移量 ×0.5 | 小屏上同样的位移在视觉上更剧烈 |
| 不为移动端"取消"动效，只"减轻" | 小屏一屏内容少 → 更需要阅读顺序引导 |
| 不做 hover-only 的信息揭示 | 触屏上没有 hover → 信息会永久不可达 |

**关键**：移动端降级的目标是"同样的信息，更少的运动"，
**不是**"更少的信息"。任何在移动端被隐藏的内容都是 bug。

## 6. Performance Constraints（性能约束）

| 属性 | 评级 | 说明 |
|---|---|---|
| `transform` / `translate` | ✅ 合成 | 只走合成层，不触发绘制 |
| `opacity` | ✅ 合成 | 同上 |
| `filter` / `backdrop-filter` | ⚠️ 昂贵 | 每帧重新采样；同屏 ≤ 2 处 |
| `width/height/top/left/margin` | ❌ 禁止动画 | 触发布局重排，整页抖动 |
| `background-position` | ❌ 禁止动画 | 每帧触发 paint；用 `transform` 位移替代 |
| `box-shadow` | ❌ 禁止动画 | 每帧重绘阴影；改用伪元素 + opacity |

### 预算

| 项 | 上限 |
|---|---|
| 同屏持续动画（infinite） | **≤ 1** |
| 同屏 `backdrop-filter` | **≤ 2** |
| 同屏发光元素 | **≤ 1** |
| 单元素同时动画属性数 | ≤ 3 |
| 单页 `will-change` 元素数 | ≤ 6（揭示完成后必须释放） |

## 7. 交付前自检

- [ ] 每一个动效都能说出它属于四类角色中的哪一类
- [ ] L3 时长 < L2 < L1（层级顺序与时长顺序一致）
- [ ] 交互动效全部 ≤ 1000ms（instrument ≤ 220ms）
- [ ] 没有任何动画作用在 `width/height/top/left/margin/background-position` 上
- [ ] 所有指针驱动的动效都做了 rAF 合并
- [ ] 同屏持续动画 ≤ 1
- [ ] `prefers-reduced-motion: reduce` 下：位移与持续动画全部消失，信息完整
- [ ] 触屏下：视差与环境动效关闭，位移减半，hover-only 信息有替代揭示方式
- [ ] 每个动画元素都能回答"如果删掉它，用户会损失什么信息？"
      （如果答案是"没有"，那就删掉它）

## 8. 常见失败模式

| 失败 | 表现 | 修正 |
|---|---|---|
| **animation everywhere** | 卡片悬浮、按钮抖动、图标旋转同时存在 | 每个动效必须归入四类角色之一 |
| **无信息量的持续动画** | 背景一直流动 | ambient 必须可关闭，且同屏 ≤ 1 |
| **时长倒挂** | 按钮反馈 400ms，页面入场 200ms | L3 < L2 < L1 |
| **用 `ease-in` 做进入** | 感觉"卡了一下才出来" | 进入一律用 `ease-out` |
| **指针动效未合并** | 高刷屏上掉帧 | rAF 合并写入 |
| **reduced-motion 只写 CSS** | 用户运行中改偏好无响应 | CSS + JS 双保险 |
| **移动端直接取消动效** | 小屏失去阅读顺序引导 | 减轻而不是取消 |
| **hover-only 信息** | 触屏用户永远看不到 | 提供常驻或点击展开 |
