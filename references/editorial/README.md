# Reference Board · editorial

> 编辑式设计语言：印刷传统、强排版、大留白。
> 本文件**只做设计语言分析**，不含任何外部源码。

---

## 设计语言的四个来源

### 1. 报纸与杂志的「书眉行」（running head）

报纸每一页顶部都有一行小字：版名 + 日期 + 版号。它从不抢注意力，
但你失去它会立刻觉得页面"没有边界"。

- **提取**：导航不必是"带背景的横条"。一行 uppercase 小标签 + 一条 1px 横线
  就能建立同样的空间锚点，且完全不占视觉重量。
- **不可借鉴**：报纸的多栏栅格 —— 屏幕阅读流是单栏的，强行多栏会破坏顺序。

### 2. 书籍排版的「导语段」（lead paragraph）

书籍与长文常用第一段放大 1.2–1.4 倍来吸引读者进入正文。

- **提取**：`.kits-lead` —— 正文 ×1.2、宽度收到 46ch、颜色比正文更重。
- **为什么有效**：它给读者一个"入口"，而不需要在标题和正文之间加装饰。

### 3. 瑞士排版的「尺度层级」

同一页面只用 3–4 个字号层级，靠尺度差（而不是靠颜色或装饰）建立结构。

- **提取**：`display 4.5rem` / `title 1.375rem` / `body 1.0625rem` / `label 0.6875rem`。
  四档，跨过两个数量级。
- **不可借鉴**：瑞士排版的严格网格对齐（网页的中文标点与西文混排会让它失效）。

### 4. 年报与投资人信的「数据即文字」

一份好的年报里，数字是以**文字**的形式被排出来的：衬线、大字号、等宽对齐，
读者是"读"数字，而不是"看"图表。

- **提取**：`.kits-data` —— 衬线、2.75rem、`tabular-nums`、字距收紧到 −0.02em。
  关键：**字距是负的**。大字号衬线不加负字距会散开。
- **反例**：彩色徽章 + 趋势箭头 + 迷你图。那是 dashboard，不是年报。

## 关键数值关系（editorial 的"语法"）

| 关系 | 值 | 为什么 |
|---|---|---|
| 标题行高 | **1.02** | 大到必须压行高，否则上半部分是空的 |
| 标题字距 | **−0.022em** | 大字号衬线默认字距太松 |
| 段落间距 | 96px | 是主要的设计手段，不是"间隔" |
| 间距脉搏 | **4px** | 4px 是"文件与图表"的节奏；8px 会显得松散 |
| 分隔线不透明度 | 0.14 | 只做分隔，不做边界 |
| 正文宽度 | 58ch | 超过 70 字符，回行会让眼睛迷路 |

---

## 视觉签名（三个一眼可辨的动作）

1. **一个巨大的衬线标题 + 下面一条 1px 横线**（不是卡片，不是背景色块）。
2. **等宽 uppercase 小标签**（书眉行），字距 +0.16em。
3. **衬线大字号读数 + tabular-nums**（数据以文字形式被排出来）。

---

## 反模式（editorial 最常被做坏的方式）

| 反模式 | 结果 |
|---|---|
| 给每个区块加卡片 | 留白消失 → 变成普通后台 |
| 用投影表达层级 | 纸不投影 → 立刻变成"卡片式 SaaS" |
| 三色以上的图表 | 印刷图表只有墨色 + 一个强调色 |
| 正文行高 1.3 | 中文衬线 1.3 读两段就累 |
| 标题用无衬线 | 排版性格丢失，只剩"字大" |
| 正文 uppercase | 大写只属于标签层 |

## 与其它 pack 的区分点（灰度化后仍可见）

| 对比 | editorial | 另一个 pack |
|---|---|---|
| vs cinematic | 无阴影、无光、方角（0）、纸纹 | 有投影、有光、圆角 14px、玻璃 |
| vs instrument | 衬线、96px 段落间距、无边框 | 等宽、32px 段落间距、处处 1px 边界 |
