# Reference Board · instrument

> 工业仪表、监控终端、工程工具的设计语言。
> 本文件**只做设计语言分析**，不含任何外部源码。

---

## 设计语言的四个来源

### 1. 工业 HMI 的「机柜分格」

工业控制面板把每一块功能切成一个**有物理边界**的模块，配一块铭牌表头。
这不是审美选择 —— 是因为操作员需要在 0.5 秒内找到"压力表在哪"。

- **提取**：`.kits-surface` + `.kits-panel-head`（2px 底线 + 下沉底色 + uppercase 等宽标签）。
  **每个区块都有边界**，因为找得到比好看更重要。
- **不可借鉴**：真实面板的物理尺寸（
  屏幕上不需要 80mm 的按钮间距）。

### 2. 终端与仪表盘的「等宽读数」

Bloomberg 终端、示波器、万用表：所有数字都是等宽的，因为需要**逐位比对**。

- **提取**：全站等宽（含正文！）+ `tabular-nums` + `slashed-zero`。
  `slashed-zero` 是关键细节：区分 `0` 与 `O`，这在密集读数里是正确性问题。
- **不可借鉴**：终端的纯黑背景与纯白文字（长时间注视的对比过高）。

### 3. 工程图纸的「刻度」

工程图纸上没有任何"装饰性"的东西：每条线都是量尺，每个标记都有单位。

- **提取**：网格是**刻度**而不是背景纹理（32px + 22% 淡出，几乎不淡出）；
  `.kits-tick-rule`（8px 周期刻度尺）装饰性但可被理解为量尺。
- **不可借鉴**：把整套网格铺满一屏（屏幕上会变成摩尔纹）。

### 4. 机械公差的「小圆角」

工业产品的圆角来自制造工艺（倒角、最小弯曲半径），不是设计选择 ——
所以它**小到几乎看不见**（1–3px），而不是"8px 现代圆角"。

- **提取**：`--kits-radius-surface: 2px`（editorial 是 0，那是印刷直角；语义不同）。
- **为什么重要**：半径超过 4px，界面立刻从"仪表"变成"消费级 App"。

## 关键数值关系（instrument 的"语法"）

| 关系 | 值 | 为什么 |
|---|---|---|
| 正文字体 | **等宽** | 唯一的例外是超长说明文 |
| 数字 | `tabular-nums slashed-zero` | 刷新时列不跳；0 与 O 不混 |
| 标题字距 | **+0.02em** | 等宽小字号必须开字距才可读 |
| 段落间距 | **32px** | 一屏就是一张表；留白 = 少一个指标 |
| 控件高度 | **28px** / 行高 32px | 密集是功能，不是妥协 |
| 半径 | **1–3px** | 机械公差，不是设计选择 |
| 边框 | **处处 1px**（强调 2px） | 找得到比好看重要 |
| 内容宽度 | **88rem** | 比其它 pack 宽，为了放更多列 |
| 动效上限 | **220ms** | 仪表不做慢动作 |

---

## 视觉签名（三个一眼可辨的动作）

1. **一屏被 1px 实线切成网格的小面板**（不是卡片，是模块）。
2. **铭牌表头**：2px 底线 + 下沉底色 + 10px uppercase 等宽标签。
3. **左侧 2px 强调条 + 等宽大号读数**（`.kits-readout`）。

---

## 反模式（instrument 最常被做坏的方式）

| 反模式 | 结果 |
|---|---|
| 用无衬线比例字体做读数 | 数值变化时列会抖 |
| 半径 > 4px + 柔和投影 | 立刻变成消费级 Dashboard |
| 给网格加"流动"动画 | 24 小时无意义耗电 + 干扰对真实变化的感知 |
| 装饰性渐变 / 霓虹光 | 颜色必须携带语义 |
| 超过 3 个数据系列颜色 | 颜色失去语义 |
| 大留白（段落 > 48px） | 一屏就是一张表，留白 = 少一个指标 |
| 10px 标签承载唯一关键信息 | 可读性风险 |
| 用颜色单独表达正负 | 灰度/色盲用户失去信息 |

## 与其它 pack 的区分点（灰度化后仍可见）

| 对比 | instrument | 另一个 pack |
|---|---|---|
| vs editorial | 等宽全文、32px 段落、处处 1px 边界、2px 半径 | 衬线、96px 段落、只用横线、0 半径 |
| vs cinematic | 无发光、无投影、平面、极密 | 发光曲线、有投影、玻璃、中密度 |

> **判定**：instrument 是唯一一套"灰度化之后页面看起来像被切成格子"的 pack。
> 差异来自**边界哲学**（处处有边界 vs 靠空间/光分区），不是密度或颜色。

## 参考方向（链接级，不复制内容）

| 方向 | 看什么 |
|---|---|
| 观测类开源面板（Grafana 类） | 密度取舍：一屏放多少指标才不至于不可读 |
| 航空/核电控制面板的人机工程 | 铭牌表头的写法、告警的视觉层级、颜色语义纪律 |
| 示波器 / 万用表 / 频谱仪面板 | 读数与刻度的关系、单位的位置 |
| 工程制图标准（ISO / 国标） | 刻度、线宽层级、标注方式 |

**再次强调**：提取的是**语言**（边界哲学、密度取舍、读数纪律），
不是复制面板布局。任何与某个具体监控产品高度相似的产物都应当重做。
